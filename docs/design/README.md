# Design

- [Design laws](laws.md): the owner's rules that bind every screen (law 1, nothing is cut off;
  law 2, only free-length data shortens, in the middle).
- [Decision record 0027](../decisions/0027-design-direction.md): the direction (Herbarium for
  light, Night garden for dark), the status words and status leaf, notifications, the wordmark
  and the approved extras (19 October 2026).
- [Editor 2.0](editor-2.md): the owner's design of the replacement editor (phase A specs S-25 to
  S-27).

The design pass runs in three stages: D1 a screenshot gallery of today's app and an audit
(`d1-audit.md`, with the law 1 check in CI); D2 the mock-ups, from the owner and the design
review, approved by the owner; D3 building them screen by screen, with before and after
screenshots.
