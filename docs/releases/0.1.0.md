# 0.1.0: internal milestone notes (M2 complete)

**Internal milestone label, not a release.** "0.1.0" names the point where milestone M2 (Graft:
replacements) is complete. There is no tag, no GitHub release and no download: Verdra has no
public release before 1.0.0, and no outside testers before the beta milestone, M7 (plan 16.2,
decision record 0026). The owner tests from source (`tools\run-latest.ps1`) and with short-lived
CI builds. The evidence for M2 is in [docs/m2/exit-gate.md](../m2/exit-gate.md).

## What works at this milestone

- **Replace a picture or a mesh** in a Roblox game with another Roblox asset (Asset ID), a file
  from the computer (Local file: PNG, JPEG, KTX2 or DDS pictures; Roblox mesh files or OBJ), or
  an HTTPS link (URL), or make it disappear (Remove). Tested in game on Windows: pictures near and
  far, with transparency; meshes from an OBJ file, from an asset ID, and Remove.
- **Profiles:** group replacements and turn them on and off. **Apply now** puts them to work.
- **Nothing hidden, nothing permanent:** Settings › System changes lists everything Verdra
  changed outside its own folders, and **Reset everything** undoes all of it.

## Known limits

- **Windows only.** Linux and macOS are paused, planned later.
- **Not signed.** A built copy makes Windows SmartScreen say "Windows protected your PC"
  (**More info**, then **Run anyway**).
- **A replaced mesh keeps the part's own texture.** Verdra replaces the shape only; the texture
  is a separate asset and is drawn on the new shape through its texture coordinates, which is why
  the 12 October test showed dark, patterned meshes. Replace the texture too for a different one.
- **Roblox Player only**, started through Verdra. Not Roblox Studio.
- Sounds, animations and other asset types from a file or link aren't supported yet, nor
  TexturePack slots. A mesh is sent with one level of detail.
- If Roblox asks for an asset by its content hash, Verdra can't replace it yet; Activity says so.

## Builds at this milestone

- From source: `docs/guides/run-from-source.md`.
- The release dry run (`.github/workflows/release.yml`, started by hand) makes
  `Verdra-0.1.0-windows.zip` exactly as a user would get it and keeps it as a workflow artifact

## Privacy

No telemetry, no analytics, no crash reports. Verdra talks to Roblox (only what the Roblox client
asks for, and the asset lookups the user starts) and to the links the user enters. See
[PRIVACY.md](../../PRIVACY.md).
